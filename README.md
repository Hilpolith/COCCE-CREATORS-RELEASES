## About COCCE Creators

COCCE Creators is a creator studio for audience, content, and campaign insights. Use the [COCCE Creators web portal](https://cocce-creators.vercel.app/) to access the web app.

## Requirements and installation

- **Minimum Android version:** Android 7.0 (API 24) or later.
- **Network:** Internet access is required for sign-in and live portal data.

To install, download `COCCE-Creators.apk` on your Android device, open it, and follow the Android installation prompt. If asked, allow the browser or file manager you used to download it to install apps. To confirm the installed version, open Android **Settings → Apps → COCCE Creators** and check the app version; this release is **1.0.1**.

## Release or installation help

Report release or installation issues in the [COCCE Creators releases issue tracker](https://github.com/Hilpolith/COCCE-CREATORS-RELEASES/issues).

COCCE Creators releases remain separate from the COCCE Super App release repository. Do not use Super App APKs to update COCCE Creators, or vice versa.
